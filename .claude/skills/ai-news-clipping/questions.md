# AI 뉴스 클리핑 스킬 — 요구사항 & 확인 질문

## 요청 요약
- 기준 날짜: **어제** (실행일 기준, 로컬 타임존)
- 주제: **AI 뉴스 10개**
- 출처: **Top-tier 매체만** — The Economist, The New York Times
- 결과물: **HTML 파일**, **Linear 스타일** 디자인
- 스킬 구성: **Role / Rubric / Context / Tools / Workflow / Guardrail**

```
스킬 만들어줘. 그 전에 질문에 대해서 따로 파일 만든 다음에 진행해줘.

  뉴스 클리핑 스킬을 만들 예정이야.
  어제 날짜를 기준으로 AI 뉴스 10개를 뽑아주면 좋겠어.
  TopTier 저널에서만, 이코노미스트, 뉴욕 타임즈

  html 파일로 만들어줘.
  리니어 스타일로 예쁘게  만들어줘.

  Rolerubric , Context ,Tools ,workflow , Guardrail 포함해서.
```

## 확인 질문 (답변이 없어 기본값으로 진행)

| # | 질문 | 적용한 기본값 |
|---|------|---------------|
| 1 | "어제"의 기준 타임존은? | 한국 시간(KST). 기사 게재일은 미국 동부(ET) 기준으로 1일 오차를 허용 |
| 2 | 출처는 Economist·NYT 두 곳만인가, 다른 Top-tier(FT, WSJ 등)도 허용하나? | **두 곳만** 사용 |
| 3 | 어제 기사가 10개 미만이면? | 다른 매체로 채우지 않음. 찾은 개수만 싣고 부족분을 HTML에 명시 |
| 4 | "AI 뉴스" 범위는? | AI 기술·기업·정책·규제·투자·반도체·사회적 영향 포함 |
| 5 | 요약 언어는? | **한국어** 요약 + 원문 영어 제목 병기 |
| 6 | 기사별 포함 항목은? | 매체, 원제, 한글 제목, 3줄 요약, 왜 중요한가, 카테고리 태그, 원문 링크 |
| 7 | 라이트/다크 모드? | Linear 특유의 **다크 기본** + 라이트 모드 자동 대응 |
| 8 | 저장 위치·파일명은? | `./news-clipping/ai-news-YYYY-MM-DD.html` |
| 9 | 스킬 이름/호출 방식은? | `/ai-news-clipping` (프로젝트 스킬, `.claude/skills/`) |

> 기본값을 바꾸고 싶으면 이 파일을 수정하거나 알려주세요. 스킬의 SKILL.md에 반영하겠습니다.
