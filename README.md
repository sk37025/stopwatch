# kearney-ai-education

Claude Code로 만든 HTML 스탑워치 실습 결과물입니다. 빌드나 설치 없이 `output/` 폴더의 HTML 파일을 브라우저로 열면 바로 동작합니다.

## 폴더 구조

```
.
├── README.md
└── output/
    ├── stopwatch.html           # 크로노 스탑워치 (크로노그래프 손목시계 디자인)
    └── digital-stopwatch.html   # 디지털 스탑워치 (손에 쥐는 LCD 스탑워치 디자인)
```

## 결과물

### 1. 크로노 스탑워치 — `output/stopwatch.html`

크로노그래프 손목시계를 본뜬 메인 스탑워치입니다.

- **시계:** 스틸 케이스와 남색 다이얼, 타키미터 베젤(60~500)이 있습니다.
- **바늘:** 주황색 크로노 초침이 1/5초 눈금 위를 쓸고 지나갑니다. 30분·12시간 서브 다이얼이 있고, 시침과 분침은 현재 시각을 가리킵니다. 6시 창에는 랩 수가 표시됩니다.
- **푸셔:** 케이스 오른쪽 위 푸셔는 시작·정지, 아래 푸셔는 랩·초기화입니다.
- **숫자 표시:** 슬롯머신 릴처럼 숫자가 굴러가며 바뀝니다.
- **랩 기록:** 구간 시간과 누적 시간을 보여주고, 막대로 구간 길이를 비교합니다. 가장 빠른 구간은 초록, 가장 느린 구간은 빨강입니다.
- **기록 유지:** 측정 상태와 랩 기록이 브라우저(localStorage)에 저장되어 새로고침해도 유지됩니다.
- **화면:** 라이트·다크 모드와 모바일 화면을 지원합니다.

| 키 | 동작 |
| --- | --- |
| `Space` | 시작 / 정지 |
| `L` | 랩 (측정 중) |
| `R` | 초기화 (정지 상태) |

### 2. 디지털 스탑워치 — `output/digital-stopwatch.html`

손에 쥐는 디지털 스탑워치 사진을 참고해 만든 버전입니다.

- **외관:** 검은 케이스, 빨간 링, 파란 테두리의 LCD 창이 있습니다.
- **숫자 표시:** 7세그먼트 숫자로 `분:초.1/100초`를 표시합니다. 액정 윗줄에는 오늘 요일이 표시됩니다.
- **버튼:** 오른쪽 위는 시작, 왼쪽 위는 정지, 위쪽 가운데는 초기화(정지 상태에서만)입니다.
- **누르기 모션:** 버튼을 누르면 손가락이 내려와 누르는 애니메이션이 나옵니다.

| 키 | 동작 |
| --- | --- |
| `Space` | 시작 / 정지 |
| `R` | 초기화 (정지 상태) |

## 작업 기록

1. 기본 스탑워치를 만들었습니다(다이얼, 숫자 표시, 랩 기록, 단축키).
2. 숫자 표시를 슬롯머신 릴 형태로 바꿨습니다.
3. 참고 사진을 바탕으로 디지털 스탑워치를 따로 만들고, 초기화 버튼과 손가락 누르기 모션을 추가했습니다.
4. 크로노 스탑워치를 스틸 크로노그래프 디자인으로 개편했습니다(타키미터 베젤, 서브 다이얼, 작동하는 푸셔, 랩 비교 막대).
5. 결과물을 `output/` 폴더로 옮기고 이 README를 추가했습니다.
